# Battlecard Templates

This directory contains templates for rendering battlecards in various formats.

## Template Types

- `competitive.html` - Competitive battlecard HTML template
- `objection.html` - Objection handling card template
- `comparison.html` - Feature comparison matrix template
- `winloss.html` - Win/loss analysis template

## Usage

Templates use Jinja2 syntax and are rendered by the battlecard service
when exporting to HTML or PDF formats.

## Styling

Templates reference styles from `/data/templates/styles/` for
brand-consistent output.
