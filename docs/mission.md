# Mission

Build a VP-of-Sales Operating System using Claude Code Cloud. The product
- Automates transcript analysis and CRM entry
- Generates sales content decks, proposals, battlecards
- Connects to tools like HubSpot and Avoma
- Enriches prospect data from events, lists, and outreach
- Coaches based on Winning by Design's SPICED methodology

All features must be WbD-aligned, elegantly branded, and conflict-free.
