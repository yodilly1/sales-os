## Responsibilities

### Backend - HTML Renderer
1. Enhance `backend/app/services/rendering/html_renderer.py`
2. Create base HTML template with your styling
3. Create content-type specific templates:
   - `deck_template.html` - slide-based layout
   - `proposal_template.html` - document layout with sections
   - `one_pager_template.html` - single page layout
4. Inject generated content into templates

### Backend - API
1. Add `render_html` parameter to content generation
2. Return both JSON content and rendered HTML
3. Add endpoint: `GET /api/v1/content/{id}/html` - download HTML file

### Frontend
1. Add HTML preview tab/option
2. Render HTML in iframe or modal
3. Add "Download HTML" button
4. Style toggle between JSON and HTML view

## Base HTML Template Structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{{ title }} | Generated by Sales OS</title>
    <style>
        /* Animated background */
        body::before {
            content: '';
            position: fixed;
            top: 0; left: 0; right: 0; bottom: 0;
            background:
                radial-gradient(circle at 20% 50%, rgba(100, 255, 218, 0.15) 0%, transparent 50%),
                radial-gradient(circle at 80% 80%, rgba(79, 168, 255, 0.15) 0%, transparent 50%);
            animation: backgroundMove 20s ease infinite;
            z-index: -1;
        }

        /* Glass-morphism cards */
        .card {
            background: rgba(255, 255, 255, 0.05);
            backdrop-filter: blur(20px);
            border: 1px solid rgba(255, 255, 255, 0.1);
            border-radius: 16px;
            padding: 2rem;
        }

        /* ... more styling from your templates ... */
    </style>
</head>
<body>
    {{ content }}
</body>
</html>
```

## Test Script

```bash
# 1. Start system
docker-compose up --build -d
sleep 15

# 2. Generate content with HTML rendering
curl -X POST http://localhost:8000/api/v1/content/generate \
  -H "Content-Type: application/json" \
  -d '{
    "content_type": "proposal",
    "goal": "Business case for automation",
    "product_info": {"name": "Vayu"},
    "render_html": true
  }'

# 3. Response should include:
# - content (JSON structure)
# - html (rendered HTML string)
# - html_url (link to download)

# 4. Download HTML file
curl http://localhost:8000/api/v1/content/{id}/html -o proposal.html

# 5. Open proposal.html in browser
# Should see beautiful styling, not plain HTML
```
